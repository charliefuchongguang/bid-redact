> 日期：2026-11-05

## 1. 后端接口

统一前缀 `/api`。

### 认证

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/auth/register` | 用户名 + 密码注册，返回 JWT |
| POST | `/auth/login` | 用户名或邮箱 + 密码登录 |
| GET | `/auth/me` | 当前用户 |

- JWT HS256，有效期 12 小时。
- 密码 argon2id 哈希。
- 连续失败 5 次锁定 15 分钟。

### 文件

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/files` | 上传 PDF（≤200MB，拒绝加密文件） |
| GET | `/files` | 本人文件列表（分页） |
| GET | `/files/{id}` | 文件详情 |
| GET | `/files/{id}/status` | 状态 / 进度 / 队列位置 / 遮蔽数 |
| GET | `/files/{id}/boxes` | 遮蔽框明细（不含明文） |
| GET | `/files/{id}/download` | 下载脱敏件 |
| GET | `/files/{id}/preview/{page}?dpi=150` | 服务端渲染页图 PNG |
| GET | `/files/{id}/page-meta` | 每页宽高（用于前端标注换算） |
| POST | `/files/{id}/retry` | 重新加入队列 |

### 管理端

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/admin/files` | 全部文件 |
| GET | `/admin/stats` | 状态与分类统计 |
| PATCH | `/admin/files/{id}/review` | 标记 / 取消复核 |
| POST | `/admin/files/{id}/boxes` | 新增遮蔽框并触发重新生成 |
| PATCH | `/admin/boxes/{box_id}` | 修改遮蔽框 |
| DELETE | `/admin/boxes/{box_id}` | 删除遮蔽框并触发重新生成 |
| POST | `/admin/files/{id}/reprocess` | 按现有遮蔽框重新生成 |

## 2. 队列与状态机

- 单 worker 线程，MySQL `SELECT ... FOR UPDATE SKIP LOCKED` 抢占任务。
- Mineru 并发为 1，因此进程内只允许一个任务处理。
- 状态：`pending → processing → completed / needs_review / failed`。
- 启动时把残留的 `processing` 复位为 `pending`。
- `needs_review` 触发条件：存在非 `redacted` 遮蔽框，或处理过程有告警。
- 队列位置 = 该文件之前处于 `pending` 的数量。

## 3. 数据库

7 张表（前缀 `tm_`）：`tm_users`、`tm_files`、`tm_redaction_boxes`、`tm_task_events`、`tm_audit_logs`、`tm_rule_versions`、`tm_system_config`。

- 遮蔽框 `page` 存 1 基页码，坐标单位 PDF point。
- 敏感值只存 `value_hash`（SHA-256），不存明文。
- `tm_files.redacted_path` 指向脱敏件；原文件路径不可通过 API 直接下载。

## 4. 前端页面

| 路由 | 页面 | 功能 |
|---|---|---|
| `/login` | 登录/注册 | 双 Tab |
| `/files` | 文件列表 | 状态、进度、下载、重试、自动刷新 |
| `/upload` | 上传 | 拖拽、大小校验、进度 |
| `/files/:id` | 结果页 | 服务端渲染预览 + 遮蔽框叠加 + 明细表 + 下载 |
| `/admin` | 管理后台 | 文件复核、统计 |

- 预览采用**服务端渲染 PNG**，不向前端暴露 PDF 文本层，避免复制还原。
- 遮蔽框按页面宽高百分比定位，随预览缩放。
- 颜色：红=个人隐私，橙=商业秘密，蓝=企业联系。

## 6. 已知缺口（V1.1 计划）

1. **访问审计**：`tm_audit_logs` 已建表，登录/上传/下载写审计待补齐。
2. **找回密码 / 修改密码**：当前未提供 UI 与 SMTP。
3. **Mineru 分片**：当前整份提交；超大文件需按 20 页分片，避免长任务与超时。
4. **规则库在线管理**：当前通过重启加载 `rules.yaml`，未提供后台编辑。
5. **自动化测试覆盖**：已覆盖校验位、坐标、白名单、去重、遮蔽；API 集成测试为冒烟脚本，尚未纳入 CI。
6. **导出报告**：按需求不生成 Excel/PDF 报告，结果仅在网页展示。
7. **管理员框选编辑**：结果页已支持拖拽新增、明细删除；但暂不支持拖动已有框微调。

## 7. 本地启动

```powershell
# 后端
cd backend
..\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

# 前端（另开终端）
cd frontend
npm run dev
```

访问 `http://127.0.0.1:5173`，Vite 会把 `/api` 代理到 `http://127.0.0.1:8000`。
