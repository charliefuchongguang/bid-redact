# Windows 本地交付与启动

适用于把系统安装在一台 Windows 电脑上、由普通用户直接使用的场景。

## 交付形态

- 后端 FastAPI 同时提供 API 和前端静态页面。
- 默认地址：`http://127.0.0.1:8000`
- 只启动一个服务窗口，不再需要分别启动前端和后端。
- 数据库、原件、脱敏件、缓存都在项目目录的 `data/` 下。

## 首次安装

1. 安装 Python 3.12，并勾选 `Add Python to PATH`。
2. 安装 Node.js 20+（只有首次构建前端时需要）。
3. 双击 **`首次安装.bat`**。
4. 按提示填写 `.env` 中的 `MINERU_API_TOKEN`。
5. 如已取得 InsightFace 模型授权，安装脚本会提示下载人脸模型；否则可先跳过，但身份证头像检测将不可用。

安装脚本会完成：

- 创建 `.venv` 并安装 Python 依赖
- 安装前端依赖并构建 `frontend/dist`
- 初始化 `data/app.db`
- 生成 `.env`（如不存在）

## 日常启动

双击 **`启动投标脱敏工具.bat`**。

脚本会：

1. 检查服务是否已运行；已运行则直接打开浏览器。
2. 检查运行环境和前端构建产物，缺失时给出提示或自动构建。
3. 启动一个标题为“投标文件自动脱敏 - 服务运行中”的窗口。
4. 等待 `/api/health` 就绪后打开浏览器。

关闭服务窗口即停止服务。

## MinerU Token 与重启

在「管理后台 → 系统设置」中可以直接维护 MinerU Token，不需要打开 `.env`：

- 输入新 Token 后点「保存 Token」，新任务立即使用。
- 页面按录入时间估算 3 个月有效期，显示预计到期日和剩余天数。
- 剩余 30 天黄色提醒，7 天红色提醒，过期后红色告警。
- 重新保存相同 Token 不会重置倒计时。
- 如果检测到 `.env` 被手工修改，会标注“按 .env 修改时间估算”。

「重启服务」会重新读取 `.env`、规则库和配置。重启只在通过启动脚本运行时可用，会短暂中断服务，正在处理的任务会中断。

## 更新程序

1. 关闭服务窗口。
2. 覆盖项目文件，保留 `data/` 和 `.env`。
3. 如果前端有改动，双击 `首次安装.bat` 重新构建，或手动执行：

```powershell
cd frontend
npm install
npm run build
```

4. 双击 `启动投标脱敏工具.bat`。

## 常见问题

| 问题 | 处理 |
|---|---|
| 双击启动脚本提示缺少 `.venv` | 先运行 `首次安装.bat` |
| 提示未找到前端构建产物 | 先运行 `首次安装.bat`，或安装 Node.js 后重新运行 |
| 浏览器打不开 | 查看服务窗口是否报错；确认 `http://127.0.0.1:8000/api/health` 返回 ok |
| 扫描件处理失败 | 在「系统设置」检查 MinerU Token 是否配置、是否即将/已经过期 |
| 身份证头像未遮挡 | 检查 `data/models/insightface/det_10g.onnx` 是否存在 |
| 端口 8000 被占用 | 关闭占用该端口的程序，或让管理员修改启动脚本中的端口 |

## 安全说明

- 本机访问地址仅绑定 `127.0.0.1`，局域网内其他电脑不能直接访问。
- 本地部署默认 `LOCAL_FULL_ACCESS=true`，所有登录用户拥有完整权限。
- `.env` 中的 MinerU Token 不要发给普通用户或提交到仓库。
