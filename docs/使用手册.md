# 使用手册

## 1. 登录与注册

- 打开 `https://tuomin.bjzcc.cn`。
- 未登录会跳转到登录页，可切换到「注册」创建账号。
- 注册账号默认为普通同事，仅能查看本人上传的文件。
- 管理员账号由部署时初始化，可查看全部文件。

## 2. 上传与脱敏

1. 点击顶部「上传文件」。
2. 点击选择或拖拽 PDF（单文件 ≤ 200MB，加密 PDF 不支持）。
3. 点击「开始脱敏」，系统自动加入队列。
4. 上传成功后自动进入结果页，可查看排队位置与处理进度。

> 纯文本 PDF 在本地处理；扫描/混合件调用 MinerU 官方精准解析，高峰期可能需要排队。含图片/扫描页还会在本机运行 InsightFace 人脸检测。

## 3. 结果页

| 区域 | 说明 |
|---|---|
| 顶部状态 | 排队中 / 处理中 / 已完成 / 待复核 / 失败 / 已终止 |
| 页面预览 | 服务端渲染的脱敏后页面，敏感区域为中性灰马赛克 |
| 遮蔽框 | 红/橙/蓝三色边框分别对应个人隐私、商业秘密、企业联系 |
| 处理概览 | 遮蔽总数、待复核数、分类计数 |
| 文件信息 | 页数、文档类型、规则版本、上传时间、复核状态 |
| 遮蔽明细 | 每处遮蔽的页码、规则、类型、状态；点击行可跳转页码 |
| 下载脱敏件 | 下载带马赛克的 PDF |

操作提示：

- 「上一页 / 下一页」翻页；「标准/清晰/高清」切换预览清晰度。
- 可关闭「显示标签」只看马赛克效果。
- 「重新处理」会用当前规则重新跑一遍（历史文件适用）。
- 排队中/处理中可点击「终止」；终止后如需继续，可再点「重新处理」。

## 4. 哪些信息会被脱敏

**会脱敏**

- 身份证号、身份证头像 + 号码（头像优先由 InsightFace 遮挡，未检出时回退头像模板）
- 手机号、固定电话、个人邮箱、家庭住址
- 银行卡号、银行账号、基本存款账户编号、开户行
- 证书编号、学历/职称证书编号
- 投标总价、大写金额、报价明细/合价、成本构成、合同金额、保证金、年度营业额
- 银行回执凭证号、验证码
- 联系人手机、私人微信
- 合同保密条款
- 含图片/扫描页中的人脸（FACE-01）

> 身份证默认只遮头像 + 号码，姓名、地址、出生日期等文字仍可见；上线前需业务/合规确认该策略。定位失败时回退整卡并标记待复核。

**不会脱敏（白名单）**

- 统一社会信用代码
- 资质证书名称/等级/有效期
- 业绩项目概况
- 姓名、手写签名
- 红色公章
- 招标限价/招标控制价

## 5. 管理功能

本地部署默认所有登录用户拥有完整管理权限（`LOCAL_FULL_ACCESS=true`），进入「管理后台」后可以：

- **文件复核**：查看全部文件，标记「已复核」/取消复核。
- **统计**：文件状态、遮蔽框总数、待复核遮蔽框、按类型统计。
- **规则库**：用规则清单查看和搜索当前规则，按个人隐私/商业秘密/企业联系分组；点「编辑」修改关键词、识别方式和遮挡范围；点「新建规则」添加规则。新增或修改先保存到草稿，校验后发布。
- 规则库底部折叠保留「高级模式：JSON / YAML」，供维护人员导入导出和精调；普通使用不需要打开。
- **系统设置**：直接输入或更换 MinerU Token，不需要打开 `.env`；页面会按录入时间显示预计到期日和剩余天数，剩余 30 天黄色提醒、7 天红色提醒。点击「重启服务」可重新加载 Token、规则和配置（仅通过启动脚本运行时可用）。
- 结果页右上角可直接「标记已复核/取消复核」，右侧遮蔽明细支持只看待复核、点击定位和页码跳转。
- 结果页管理员可打开「调整框」：点击遮蔽框后拖动位置、拖四角缩放，松开后自动从原文件重建；选中后可「忽略此框」，该区域恢复显示。最后一个遮蔽框不允许忽略。

规则发布只影响新上传的文件；已有文件保留其 `rule_version`。

## 6. 常见问题

| 问题 | 处理 |
|---|---|
| 上传后一直排队 | 查看结果页排队位置；高峰属正常 |
| 处理失败 | 结果页会显示失败原因，可点击「重新处理」 |
| 扫描件有遗漏 | 标记给管理员复核，必要时在结果页手动加框或补充规则 |
| 扫描件处理失败 | 在「管理后台 → 系统设置」检查 MinerU Token 是否配置、是否即将/已经过期，以及网络是否可访问 `mineru.net` |
| 更换 Token 后未生效 | 保存 Token 后点「重启服务」完全重载配置 |
| Token 剩余时间显示“估算” | 说明当前是旧 Token 或手工修改过 `.env`；重新保存 Token 后按界面录入时间精确计算 |
| 人脸检测失败 | 检查 `FACE_MODEL_PATH` 模型是否存在、是否已取得授权、依赖是否安装 |
| 下载失败 | 确认状态为「已完成/待复核」且网络正常 |
| 无法查看他人文件 | 普通账号仅能查看本人文件 |

## 7. 数据与隐私

- 原 PDF 与脱敏件均保存在服务器，仅登录用户可访问。
- 系统数据库不保存敏感值明文，只保存类型、位置与哈希。
- 对外发送前请下载「脱敏件」，不要使用原文件。
- 如发现漏遮，请立即停止外发并联系管理员复核。
