# 第三方数据处理与合规说明

> 适用系统：投标文件自动脱敏服务  
> 第三方服务：MinerU 官方精准解析 API（`https://mineru.net/api/v4`）  
> 版本：v1.0（2026-11-06）

## 1. 目的

本系统在本地完成投标 PDF 的敏感信息定位与遮蔽。仅当文件包含扫描页（纯扫描件或混合件）时，才需要调用第三方 OCR/版面解析服务获取文本与坐标。本文说明该场景下的数据流、最小化措施、安全要求与上线前需确认的合规事项。

## 2. 数据流

1. 用户上传原始投标 PDF，保存在本系统 `data/original/`。
2. 系统在本地判断页面类型：
   - 纯文本 PDF：不调用第三方，直接在本地用 PyMuPDF 定位与遮蔽；
   - 扫描/混合 PDF：进入第 3 步。
3. 对超过 200 页或 200MB 的文件，先在本地拆分为多个分片。
4. 通过 HTTPS 将分片上传至 MinerU 官方 API，提交参数包括：
   - 文件名、`data_id`、页范围、是否 OCR；
   - 模型版本、表格/公式开关、语言。
5. MinerU 返回解析结果 ZIP（含 `content_list.json`、`layout/middle.json`、Markdown、图片等）。
6. 系统仅读取 JSON 中的文本、表格 HTML 与 bbox；图片资源不落盘、不保留。
7. 解析结果缓存于本地 `data/mineru/cache/`（仅 JSON），用于同一文件重复处理时避免再次上传。
8. 系统在本地完成敏感信息定位、物理移除、马赛克与自检，生成脱敏件 `data/redacted/`。

## 2.1 InsightFace 人脸检测

- 人脸检测在**本机**完成，不把页面图片或人脸数据上传到 InsightFace 或任何第三方。
- 仅对含图片/扫描页的页面渲染并检测；渲染图只在内存中使用，不落盘。
- 人脸检测结果仅保存页码、矩形坐标、置信度到本地 SQLite/JSON 缓存。
- InsightFace 代码为 MIT 许可；预训练模型按官方许可使用，本项目已取得相应授权。模型文件不提交仓库，仅部署在服务器 `data/models/insightface/`。
- 上线前仍需业务/合规确认：人脸属于敏感个人信息，遮挡范围、日志留存、访问权限需符合公司制度。

## 3. 数据最小化措施

- 纯文本 PDF 不离开本系统。
- 仅在存在扫描页时调用第三方。
- 大文件本地分片，避免一次性上传超大文件。
- 第三方返回的图片、Markdown、临时 ZIP 不保留；仅保留解析 JSON。
- 本地日志不记录敏感原文，仅记录规则、坐标、哈希与状态。
- MinerU Token 仅存放于服务器 `.env`，不写入代码、不提交仓库、不返回前端。

## 4. 第三方数据保留与传输

- 传输链路使用 HTTPS。
- 第三方服务端的数据保留期限、是否用于模型训练、日志留存策略，以其服务条款与隐私政策为准。
- 上线前须由法务/信息安全确认：
  1. 是否已签署数据处理协议（DPA）或等效条款；
  2. 数据存储地域与跨境传输要求；
  3. 是否允许将含个人信息、商业秘密的投标文件提交第三方 OCR；
  4. 第三方的删除机制与保留周期。
- 如上述任一事项无法满足，应改用本地化/私有化解析方案，或仅对已脱敏/去标识化文件调用第三方。

## 5. 安全要求

1. 服务器与 MinerU 之间仅开放 HTTPS 出站。
2. `.env` 权限 600，Token 上线后轮换，泄露时立即吊销。
3. `data/` 不放入 Nginx 静态目录，仅通过 API 鉴权访问。
4. 原始投标文件与脱敏件均为敏感数据，备份介质需加密。
5. 仅授权人员可访问管理后台与规则库；操作留痕（规则审计、任务事件）。
6. 出现漏遮、误传或 Token 泄露时，立即停止对外发送并启动事件响应。

## 6. 上线检查清单

- [ ] 已确认 MinerU 服务条款、隐私政策与数据保留策略。
- [ ] 已完成个人信息/商业秘密第三方处理的内部审批。
- [ ] 已确认数据存储地域与跨境传输合规性。
- [ ] `MINERU_API_TOKEN` 仅存在于服务器 `.env`，权限 600。
- [ ] 已配置每日页数上限（默认 1000 页）。
- [ ] 已验证纯文本文件不触发第三方调用。
- [ ] 已验证解析结果仅保留 JSON，图片不落盘。
- [ ] 已确认 InsightFace 模型授权范围，模型文件仅部署在受控服务器。
- [ ] 已验证人脸检测在本机完成，页面图片不上传第三方。
- [ ] 已制定 Token 轮换与泄露处置流程。
- [ ] 已向使用者告知扫描件可能提交第三方解析。

## 7. 待确认事项

- MinerU 官方服务的实际运营主体、数据处理协议模板与保留期限。
- 是否需要对投标文件中的个人信息做前置去标识化后再提交 OCR。
- 是否建设本地 MinerU 私有化部署，作为高敏文件的替代通道。
- 第三方调用失败时的业务降级策略（当前策略为标记失败，不降级到内部 router）。
